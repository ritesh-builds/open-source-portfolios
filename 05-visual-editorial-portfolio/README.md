## ✨ Features

- 🖼️ **Visual-First Layout:** Prominent photo/avatar presentation balanced with rigorous engineering copy.
- ⚡ **Data-Driven Core:** All sections update dynamically from `lib/portfolio-data.ts`.
- 📊 **Metric Highlights & Engineering Lists:** Showcase request volumes, latencies, and technical decisions.
- 🧩 **DSA Problem Solving Section:** Display your algorithmic progress with difficulty meters.
- 📱 **Adaptive Design:** Fluid typography and flexible grid systems tailored for all device sizes.

## 🚀 Quickstart

```bash
git clone https://github.com/your-username/visual-editorial-portfolio.git
cd visual-editorial-portfolio
npm install
npm run dev
```

---

## 🛠️ Personalization

Open **`lib/portfolio-data.ts`** and configure:

1. `ABOUT_ME` — Your name, title, profile image (`/public/your-photo.jpg`), and bio.
2. `PROJECTS` — Your projects with metrics, highlights, and GitHub links.
3. `SKILLS` & `SOCIAL_LINKS` — Your technical tools and online profiles.
