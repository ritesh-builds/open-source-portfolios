# 🎨 Motion & Color Theory — Developer Portfolio Template

An expressive, motion-led developer portfolio template with smooth Framer Motion transitions, customizable color palette accents, and high-density project cards.

## ✨ Highlights

- 🎭 **Smooth Motion Choreography:** Staggered entry transitions, hover elevations, and fluid interactions.
- 🎨 **Adaptive Color Harmony:** Sophisticated contrast scales tailored for both dark and light modes.
- ⚡ **Lightweight & Fast:** Zero heavy layout bloat; pure Next.js and Tailwind CSS performance.
- 🛠️ **Single File Configuration:** Edit `lib/data.ts` to customize all portfolio data in seconds.

## 🚀 Quickstart

```bash
git clone https://github.com/your-username/motion-portfolio.git
cd motion-portfolio
npm install
npm run dev
```

## 🛠️ Customization

Open **`lib/data.ts`** to update your name, links, projects, and skills:

```ts
export const about = {
  name: "Your Name",
  title: "Your Title",
  location: "Your Location",
  email: "your.email@example.com",
  intro: "Your short headline...",
  description: "Your full description...",
  photo: "/your-photo.jpg"
};

export const links = {
  github: "https://github.com/your-username",
  linkedin: "https://linkedin.com/in/your-username",
  twitter: "https://x.com/your-username",
  // ...
};

export const projects = [
  // Your projects array
];
```
