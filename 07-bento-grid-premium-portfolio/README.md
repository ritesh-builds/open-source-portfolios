# 💎 Premium Bento Grid — Developer Portfolio Template

A high-end developer portfolio inspired by modern design systems. Features **Bento Grid** layouts, interactive **Spotlight Cards**, engineering principles, and a clean typography hierarchy.

## ✨ Features

- 🍱 **Bento Grid Architecture:** Clean, modular grid blocks presenting your identity, skills, projects, and career timeline.
- 💡 **Spotlight Interactive Cards:** Subtle cursor-reactive glow effects.
- ⚡ **Instant Personalization:** Edit `lib/site-data.ts` to replace dummy data with your own projects and links.
- 🚀 **Next.js 15 & React 19:** Built with the latest App Router best practices.

---

## 🚀 Quickstart

```bash
npm install
npm run dev
```

---

## 🛠️ Personalization

Open **`lib/site-data.ts`** and update with your own name, projects, and links.
