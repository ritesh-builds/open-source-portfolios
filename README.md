# Open Source Portfolios

A collection of eight developer portfolio concepts built with Next.js, React, TypeScript, and Tailwind CSS. Each project is a standalone app with its own visual direction and README.

## Portfolio concepts

| Project | Design |
| --- | --- |
| [01 — Monochrome Minimal](./01-monochrome-minimal-portfolio/) | Minimal monochrome layout with responsive sections and a theme toggle |
| [02 — Terminal Architecture](./02-terminal-architecture-portfolio/) | Interactive terminal, architecture flows, and engineering case studies |
| [03 — DevFolio Sidebar](./03-devfolio-sidebar-portfolio/) | Sidebar navigation, project gallery, and grouped toolkit |
| [04 — Editorial Typography](./04-editorial-typography-portfolio/) | Typography-led presentation with structured project case studies |
| [05 — Visual Editorial](./05-visual-editorial-portfolio/) | Photography-forward layout with engineering highlights |
| [06 — Color Theory Motion](./06-color-theory-motion-portfolio/) | Expressive color palette, motion, and project cards |
| [07 — Premium Bento Grid](./07-bento-grid-premium-portfolio/) | Bento-style grid with interactive spotlight cards |
| [08 — Retro Geometric Monogram](./08-retro-geometric-monogram-portfolio/) | Geometric monogram artwork and a retro-modern project showcase |

## Getting started

Each numbered folder is an independent Next.js application. Choose a project and run it from that folder:

```bash
cd 01-monochrome-minimal-portfolio
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000). To run a different concept, use its folder name instead.

## Customization

Portfolio content is configured in each project's `lib/` directory. The configuration filename varies by concept; see that project's README for the exact file and customization details.
